**A video with no subtitle track inside it can now be synced: with `--vad`, tsubasa times the subtitle
against the speech in the video's own audio — and checks that the words agree before it writes anything.**

Off by default. Nothing changes for anyone who doesn't pass `--vad`.

---

## Videos with no subtitle track

BD rips and raws often carry no subtitle track, so until now tsubasa could only refuse them. With
`--vad` (`sync(..., vad=True)`) it listens instead:

- **Timing** — where speech starts in the audio, from Silero VAD. One offset per file.
- **A text check that must agree** — twelve short stretches of the audio are transcribed and compared
  with what the subtitle says *there*. Words that fit the subtitle at a different offset mean a cut or
  a different edit, and the pair is refused rather than written wrong.
- **Nothing downloaded, nothing new to install with pip** — it uses whisper.cpp 1.8.4 and two of its
  models where you already have them (for example from a subtitle-generation tool):
  `TSUBASA_WHISPER`, `TSUBASA_VAD_MODEL`, `TSUBASA_ASR_MODEL`. Any other whisper.cpp release is
  refused by name.

```
tsubasa /path/to/your/folder --vad
```

### Proven before release

47 cases with known answers, built from twelve real episodes with their subtitle tracks removed:
correct subtitles, known offsets up to 12 s, wrong episodes, cuts of 25–68 s (one with the opening
removed), audio streams that start late, four minutes of silence.

| | |
| --- | --- |
| right answers | **43 of 47** |
| a wrong file written | **none** |
| a correct subtitle refused | **none** |
| offset error | median 0.02 s; the four misses are one episode, 0.17–0.19 s early |

Thanks to **Mattias**, whose pull request ([#4](https://github.com/SonicSandbox/Tsubasa-sync/pull/4))
brought the idea of timing a subtitle against the speech itself, through whisper.cpp, with a text check
on top. This release is built on that idea.

### What it does not do (yet)

- **A subtitle in a different language from the audio is refused** on this path — an English subtitle
  on Japanese speech can't be checked word for word, so tsubasa says so instead of guessing.
- **The text check is measured on Japanese speech.** Chinese and other speech is refused on this path
  until it has been measured.
- **One offset per file**: a subtitle from an edit with a cut in it is refused, never split.
- The text check runs on the CPU: about two minutes a video with whisper's small model, once per video,
  and only when the timing already agrees.

## Getting it

**The app, no Python needed:** download `tsubasa-windows-x64.zip` below, unzip
it anywhere, double-click `tsubasa-gui.exe`. `SHA256SUMS` is the checksum.

> ⚠ Unsigned, so the first launch shows *"Windows protected your PC"* — click
> **More info**, then **Run anyway**.

**As a command or a library:**

```
pip install --upgrade tsubasa-sync
```

```
tsubasa /path/to/your/folder
```

**ffmpeg is not bundled.** Matroska files with a subtitle track inside need
nothing; any other container, and `--vad`, need `ffmpeg` and `ffprobe` on `PATH`,
or the folder holding them in `TSUBASA_FFMPEG`.
